# Installation

```bash
pip install langchain langchain-text-splitters langchain-community langchain-experimental langchain-openai pypdf openpyxl python-magic-bin
```

Or install from requirements file:

```bash
cd doc_chunker
pip install -r requirements.txt
```

## Environment Variables (for semantic chunking)

```bash
export OPENAI_API_KEY="your-api-key"
```
